# Bike-SharingDemand
I built an end-to-end data pipeline to scrape weather data via APIs, performed exploratory data analysis (EDA) with SQL, and trained multiple regression models to forecast hourly demand.
Key Insights:Peak commuting hours remain the strongest predictor of high-volume bike utilization.   Weather factors heavily depress rentals, requiring dynamic inventory planning.   The final optimized elastic net regression model achieved an R-squared of over 0.72.   Tech Stack: R (tidymodels, dplyr), SQL, ggplot2, R Shiny. 
Extracted and processed historical bike-sharing and OpenWeatherAPI data using R to prepare a robust analytical dataset.   Conducted Exploratory Data Analysis (EDA) utilizing SQL queries and ggplot2 to uncover temporal and weather-driven seasonality trends affecting urban mobility.   Developed and evaluated predictive linear regression models using tidymodels and glmnet, optimizing polynomial and interaction terms to achieve an R-squared > 0.72.
